# 自然流动海浪纹替换灯罩

依据 water_ripple_ridges_reference、water_concave_upper_reference 和 water_concave_lower_reference。宽窄不等的波带和五条独立弯曲棱线不变；内凹波谷改为顺滑弧面，凸起棱脊的折角和邻近原斜面保留。半透明青蓝PETG，作为原提灯旁的独立替换灯罩。

## 接口与造型
对应 water_shade_compatibility：高76 mm，最大外径109.6 mm，顶孔82.4 mm，底孔69.2 mm。磁铁安装环外径94 mm、高4 mm，两个Ø7.2×2.15 mm盲孔，中心X±39.2 mm，适配Ø7×2 mm磁铁。实际装配落在内胆Z32 mm面，内胆顶Z106 mm低于灯罩口Z108 mm。展示位于原提灯右侧X180 mm、Z32 mm，与原灯罩择一装配。

对应 water_ripple_surface：五道棱线分别使用不同的基准高度、起伏幅度、相位和局部宽窄分配。名义中位高度为12、23.7、39.3、50.35、64 mm，主波与次波各自按层缩放并错相；波谷控制点在相邻棱线之间沿周向移动，形成不等距、不平行的宽窄流动。控制点名义深度3.2 mm，13 mm只作为总体轴向跨度控制。上下收口保留原圆弧轮廓的分段斜面。

凹谷用二次曲线曲面与两侧原斜面相切衔接。默认过渡比例0.65：从原谷点向两侧棱线各取65%的控制腿长度作为过渡范围，凸棱附近各35%的原外斜面保留；不是固定R圆角。每道波谷随流动波带变化，内壁同步随形。外侧弧面以二次光顺放样构造，内侧用12段采样的高阶光顺放样逼近法向偏置；凸棱处不做圆角。

原控制轮廓每1°统计的四组棱间距分别约6.67–15.05、10.93–21.94、6.25–15.82、10.79–18.39 mm。保留的原宽面控制腿轴向宽度约4.10–10.32、8.56–14.84、4.35–9.97、6.96–11.74 mm，指未圆弧化控制轮廓，不是圆弧化后剩余斜面宽度，也不是壁厚。

## 壁厚与棱线检查
弧面内壁名义按外表面法向偏置1.2 mm。四条凹谷共48处外表面点到内表面的距离检查须满足1.2±0.035 mm；含凸棱附近的全部144处抽查须不低于1.165 mm、低于1.44 mm。凸棱保留尖角和内侧斜面交线，局部角隅会增厚；不是全表面逐点等厚证明。

80个原棱线采样点到外壳表面的距离小于0.0001 mm，检查原棱线位置保留。弧面两端的控制切线与原斜面一致，凸棱附近原斜面未重新光顺。内部检查同时确认磁铁环存在、两盲孔敞开而孔底有料、上下开口不堵塞，以及最终为一个有效实体。

## Making and assembly
默认半透明PETG、0.4 mm喷嘴、0.16–0.20 mm层高。灯罩竖直、底环落平台；内收肩部和水波下沿需在切片预览中检查悬垂和局部支撑。薄壁使用普通多壁切片，不用花瓶模式；1.2 mm是CAD名义壁厚，不等于保证三条实际线宽。细微锤击纹未建模，以避免薄壁尖点和清理支撑困难。

额外准备两枚Ø7×2 mm磁铁；先与内胆磁铁配对核对极性，再少量胶粘，避免胶溢进配合面。磁吸不用于提拉承重，仍从原提手提灯。先移除原灯罩，再从上方套入本灯罩，不可叠装。打印公差、透光、热量和磁力尚未实物测试。


## 几何检查与限制
已查看等轴、正视和底部斜视：凹谷曲面连贯，凸棱锐利，波带沿周向自然宽窄变化；磁铁安装环与两个孔可见。原提灯六件模型不改动。配合兼容性依据接口尺寸和外廓，未进行完整替换装配的全场干涉测试。打印、透光、热量和磁力仍需样件验证。
