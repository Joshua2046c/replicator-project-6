# 中式四件提灯

四个独立打印件：折脚拱形提手、浅圆托盘、镂空直筒内胆、薄壁灯罩。按补充角度简化，删除外伸耳座、锥台、多层法兰及三柱支架；只保留必要的磁吸环面。镂空直筒是本版默认内部实现，不声称由照片确认了隐藏结构。

用户指定灯组 Ø60×8 mm，磁铁 Ø7×2 mm。灯组品牌、电压及功率未知，保留原配线束和电源，不新增电路；空 connections 表示无新接线，不代表电气验证。

## 接口
- 灯腔 Ø60.6 mm，座面装配 Z10，8 mm 灯顶面 Z18，杯口 Z32；顶部取放孔 Ø63 mm。
- 底座—内胆 Z4、内胆—灯罩 Z32；两组磁铁孔分布半径均为39.2 mm，角度0/120/240°。孔 Ø7.2×2.15 mm，共12枚 Ø7×2 mm磁铁。
- 提手方桩中心 X±51，方桩7.8 mm配8.1 mm方孔，插深8 mm，孔深8.2 mm；方孔直接开在盘沿，胶接固定。
- 内胆直筒外径68.4 mm，灯罩下口69.2 mm，径向装配间隙0.4 mm；灯罩可从上方套入或提起，不会被顶圈扣住。
- 负Y方向8 mm宽走线缺口；内胆从灯座面开到杯口，且与一处筒壁透光口对齐；灯罩自底部向上开6 mm。
- 补充参考照片登记为 lantern_reference_side；外廓、透光口数量及隐藏结构属于设计默认。

## Making and assembly
默认0.4 mm喷嘴、0.16–0.20 mm层高；提手平放在其宽面打印，以获得连续拱形轮廓方向，底座底面向下。内胆灯杯底面向下，筒壁竖向肋低速打印；透光窗口顶部约9 mm桥接需检查切片。灯罩竖直、下环放平台，薄壁用半透明PETG；肩部检查支撑，不能用花瓶单壁模式，因为底环含磁铁盲孔。模型未实际打印。

先干试方桩和磁铁孔，需要时通过参数调整补偿。确认每对磁铁相吸后标记，少量胶粘并防止固化前移位。先粘内胆下侧，再粘上侧及灯罩磁铁。提手两方桩胶接到盘沿，胶完全固化后才可提起；直方桩的打印间隙不是防拔锁扣。

灯从内胆顶部放到底面，导线从负Y方向侧向放入缺口，再放上内胆和灯罩。底座盘沿会遮住低处一小段缺口，导线须向上绕至盘沿上方，再从灯罩底部凹口引出，不夹在磁吸面之间。磁铁若各下沉0.15 mm，两侧总气隙0.3 mm，实际吸力须样件验证。维修时先提灯罩再取内胆，禁止以灯罩代替提手悬提。灯组发热、透光、磁力承重与胶接寿命均未实测。

## 尺寸与验证边界
目标外廓140×114×210 mm。底座外径114 mm、高12 mm、底厚4 mm、内径90 mm；内胆灯杯外径88 mm，在托盘内径向间隙1 mm。提手截面10×10 mm。灯罩40道竖纹，名义径向壁厚1.8 mm、主体高76 mm；不宣称曲面法向厚度恒定。内胆总高108 mm，顶圈在灯罩上沿露出4 mm。

本次几何和外观检查以产品验证记录所指向的确切模型为准；打印公差、材料透光和实际承重仍需实物验证。
