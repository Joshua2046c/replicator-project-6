# 中式四件提灯

四个单独打印实体：提手、底座、内胆、灯罩。灯组外形依据用户上传尺寸图 Ø60×8 mm；磁铁名义 Ø7×2 mm。无控制板或 PCB；原装灯组为非索引通用成品，其型号、电压、功率未知，保持原配线束。wiring.json 的空 connections 表示无新接线，不表示已经验证灯组电路。

## 接口
- light_fit：灯腔 Ø60.6，底面装配 Z18，8 mm 厚灯顶面 Z26；顶部开口允许取放。
- magnet_joints：底座—内胆 Z12、分布圆半径41；内胆—灯罩 Z30、分布圆半径42；各三个位置 0/120/240°。孔 Ø7.2×2.15，12枚 Ø7×2 磁铁胶接。
- square_tenons：X±65 的两个方桩，7.8 mm 桩对8.1 mm 方孔，插深8 mm，胶接固定。
- wire_exit：负Y方向，8 mm宽开放槽；灯罩自底部向上6 mm，内胆从灯杯座面开到杯口。
- 参考图对应 lantern_reference 和 light_reference；外廓与配色属于默认设计，不由图像推断为实测尺寸。

## Making and assembly
默认 0.4 mm喷嘴、0.16–0.20 mm层高；提手平放在其宽面打印以获得连续拱形轮廓纤维方向，底座底面向下。内胆下法兰向下，细立柱用低速打印，顶部环桥接和底部外伸法兰需切片检查支撑。灯罩开口竖直、下环放在平台，薄壁使用半透明PETG；竖纹及肩部需切片检查，不能按花瓶单壁模式打印，因为底环含磁铁盲孔。模型未实际打印。

先干试方桩和磁铁孔，需要时通过参数调整补偿。确认磁铁极性，每对相吸后分别标记，再少量胶粘；胶固化前防止磁铁移位。内胆下侧磁铁可先粘，再粘上侧磁铁和灯罩。提手两方桩与底座方孔胶接并完全固化后再提起；直方桩的打印余量本身不是防拔锁扣。

把原装灯平放于内胆，导线从负Y开槽侧向放入；随后吸合内胆和灯罩。若磁铁下沉0.15 mm，两侧间隙合计0.3 mm，实际吸力须用选购磁铁试验。上提灯罩拆卸，禁止以灯罩代替提手悬提。原装灯发热、透光效果和磁力承重尚未实测。

## 最终尺寸与检查
装配外廓150×114×210 mm；提手截面10×10 mm，方桩仍为7.8 mm，提手止挡肩与底座接触。灯罩40道竖纹、名义径向壁厚1.8 mm，局部竖纹加厚，主体高76 mm；不宣称曲面法向壁厚处处相等。底座定位围边高2 mm，对内胆下法兰径向留0.3 mm间隙。

最终模型为四个有效实体，六对零件均无体积干涉；提手与灯罩最近间隙4.6759 mm。灯组槽实测直径60.6 mm、可用高度12 mm，容纳用户的60×8 mm灯组。灯罩磁铁孔实测Ø7.2 mm、深2.15 mm；上接口三个配对孔边重合，已核对下接口对应孔；内胆走线开口实测8 mm。确切测量记录在产品验证文件中。已看装配正面、等轴测、灯罩底部与未装灯罩的内胆，尚无实物验证。
